What this evidence supports

Classification applies to this site + observable + analysis definition + evaluated model set. Duration differences describe model response; they do not establish which terrain representation is physically closest to the Moon.

  • Each horizon value interpolates bracketing rays; witness is a sampled/interpolated DEM point, not a direct measurement
  • Profiles use bilinear representations on an aligned ray; dense plot samples are not independent observations
  • Product104 MASK/BRES/DIFF semantics from original regional README; SIGM filename mapping to its GLD03 remains inferred
  • Ancillary support does not calibrate truth probability or measurement benefit

No fine-grid W* convergence was established. Pixel spacing is not independent terrain knowledge. Observer conventions are alternative analysis definitions.
